# Merge Conflict Practice Lab

Use a disposable repository only.
1. Initialize a temporary Git repository and commit a text file.
2. Create another branch.
3. Change the same line differently on each branch and commit both changes.
4. Merge one branch to trigger a conflict.
5. Locate `<<<<<<<`, `=======`, and `>>>>>>>` markers.
6. Decide the intended final content; do not blindly choose a side.
7. Remove markers, run tests, inspect the diff, and check status.
8. Stage only the resolved files and complete the merge manually after review.

The toolkit does not resolve conflicts or stage files automatically.
