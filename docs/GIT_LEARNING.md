# Git Learning Path

## Beginner
1. Understand repository, working tree, staging area, and commit.
2. Learn `git status`, `git add`, `git diff`, and `git log`.
3. Create a disposable practice repository and make small commits.

## Intermediate
1. Create feature branches and compare branches with `git diff`.
2. Merge a feature branch in a practice repository.
3. Rehearse conflicts with the conflict lab.
4. Learn remotes, fetch, pull, and push before using them on a real project.

## Advanced
1. Understand rebase and history rewriting.
2. Learn tags and semantic versioning.
3. Practice bisect on a disposable repository.
4. Learn reflog as a recovery aid, signed commits, protected branches, and review policies.

Practice in a temporary repository, keep a backup, and read command help before running commands.
